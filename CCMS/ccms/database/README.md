# Coastal Blue Customer Credit Management System (CCMS)

## Project Overview

The Coastal Blue Customer Credit Management System (CCMS) is a web-based application designed to help businesses manage customer credit accounts digitally.

The system allows administrators to record credit sales, track customer payments, monitor outstanding balances, and provide customers with secure access to view their own account information.

---

# Features

## Administrator Module

- Secure admin login
- Dashboard overview
- Customer management
- Add, edit, delete customers
- Manage credit limits
- Record credit sales
- Record payments
- View transaction history
- Generate customer statements
- Print reports
- Manage system settings


## Customer Module

- Secure customer login
- View account balance
- View purchase history
- View payment history
- Download/print statement
- Update profile
- Change password
